## 🚀 О проекте

Учебный проект, разработанный в рамках программы ITStep Academy. Сайт представляет собой SPA-подобный интерфейс с модульной архитектурой, динамической загрузкой данных и адаптивным дизайном.

**Ключевые особенности:**
- **Динамическое расписание** — табло прилётов и вылетов, получающее данные через REST API.
- **Каталог флота** — карточки самолётов с характеристиками.
- **Модульный подход** — использование ES6-модулей для разделения логики.
- **Оптимизация** — production-сборка через Parcel с минификацией.

## 🌐 Функциональность

- **Главная страница** (`/`) — расписание рейсов (прилёт/вылет) с цветовой индикацией статусов.
- **О компании** (`/html/about-us.html`) — информация об авиакомпании.
- **Флот** (`/html/fleet.html`) — карточки воздушных судов с характеристиками.

## 💻 Локальный запуск

Для запуска проекта на вашей машине потребуется [Node.js](https://nodejs.org/) (версия 18.x или выше).

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/makmatvey/ITStepFinalProject.git
   cd ITStepFinalProject
2. **Установите зависимости:**
   ```bash
   npm install
   npm i kill-port
3. **Запустите сервер разработки:**
   ```bash
   npm run start

## 🏗 Архитектура и API

Проект использует разделение на статический фронтенд и внешний API (JSON Server), развёрнутый на отдельном инстансе Vercel.

**Структура проекта:**
```text
├── src/
│   ├── index.html          # Главная точка входа
│   ├── html/               # Внутренние страницы
│   ├── css/                # Стили (разбиты по компонентам)
│   ├── js/                 # Логика (модули для каждой страницы)
│   └── img/                # Ассеты
├── db.json                 # База данных для эмуляции API
├── vercel.json             # Конфигурация проксирования запросов к API
└── package.json            # Зависимости и скрипты
